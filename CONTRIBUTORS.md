# Contributors

This file is maintained by hand. GitHub's automatic contributors graph is generated from
commit authorship by GitHub accounts; AI tools do not get their own entries there (there
is no bot account to attribute commits to), so the attribution below complements it.

  maintainer. Owns the product direction, architecture and release decisions; develops,

## AI-assisted development

- **[OpenAI Codex](https://openai.com/codex/)** — an AI coding tool by OpenAI that
  assisted with the actual development of ClipBridge under the direction and review of
  the maintainer. Codex is a tool, not a person and not a GitHub account: it holds no
  maintainer responsibilities and makes no independent decisions. All changes are
  directed, reviewed, integrated and released by the maintainer, who remains the author
  of record for the published code.
