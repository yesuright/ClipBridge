# ClipBridge v1.1.0 Release Notes / 发布说明

Release date / 发布日期: 2026-10-31 · Client / 客户端 **1.1.0** · Relay / 中继 **1.0.0**（未变更 / unchanged）

Package / 安装包: `ClipBridge-v1.1.0-win-x64.zip` (self-contained, no installer / 免安装)

---

## English

### Highlights

- **.NET 10 LTS migration.** The Windows client now runs on .NET 10 (`net10.0-windows`) with the
  10.0.13 runtime embedded — still self-contained: no .NET install, no Python, no admin rights.
  Product behaviour, the relay protocol, storage and configuration formats are unchanged, so the
  upgrade from v1.0.0 is a drop-in replacement.
- **Connection setup is now reachable where you look for it.** The Home *iPhone connection* card and
  the Settings *Data & diagnostics* section each have a real **Connection setup** button (the tray
  menu keeps its existing `Connection setup…` entry). All three open the same read-only dialog with
  the LAN address and the device token. The old truncated gray `Authentication: Configured ·
  Connection setup` label is a plain status line again — no more guessing whether gray text is
  clickable, and no more hunting for a PowerShell step.
- **High-DPI fix for the connection dialog.** On 125%/150% monitors the *Connect your iPhone*
  dialog previously opened at its 96-DPI size with clipped buttons; it now scales with the monitor
  DPI (the 100% rendering is unchanged).

### Details

- Client: .NET 8 → **.NET 10 LTS** (`net10.0-windows`, SDK pinned to 10.0.402, runtime floor 10.0.13),
  `global.json`-enforced and verified at build time.
- New UI regression tests cover the setup entry points: buttons fire the shared callback, entries
  stay usable without a LAN address, the main window never displays masked token text, the dialog
  keeps the token masked by default and never rewrites the config, and layout stays inside bounds at
  minimum window size across 96–192 DPI.
- Relay: **no functional change** — the Python relay stays at 1.0.0 and the Shortcuts API
  (`/api/v1/clips`, `/api/v1/clips/shortcut`, `/api/v1/clips/latest`), bearer-token auth and default
  port 8787 are untouched. Existing iPhone Shortcuts keep working without edits.

### Upgrade notes (from v1.0.0)

- Replace the old folder with the new one (or extract alongside and switch). `config.json`, the
  device token, clipboard history and appearance settings are all kept — nothing is regenerated by
  opening the connection dialog.
- `verify-daily` / `verify-portability` harnesses, `--doctor` and the tray workflow behave as before.

## 中文

### 亮点

- **迁移到 .NET 10 LTS。** Windows 客户端升级至 .NET 10（`net10.0-windows`），内嵌 10.0.13 运行时，
  依旧 self-contained：无需安装 .NET、无需 Python、无需管理员权限。产品行为、中继协议、存储与
  配置格式完全不变，从 v1.0.0 升级即解压即用。
- **连接设置随手可及。** Home 页「iPhone connection」卡片与 Settings 页「Data & diagnostics」各自
  提供真正的 **Connection setup** 按钮（托盘菜单保留原有 `Connection setup…`）。三个入口打开同一个
  只读窗口，展示局域网地址与设备 Token。旧的灰色截断文字 `Authentication: Configured · Connection
  setup` 恢复为纯状态显示——不再需要猜测灰字能不能点，也不再需要 PowerShell。
- **连接窗口高分屏修复。** 在 125%/150% 缩放的显示器上，*Connect your iPhone* 窗口此前按 96-DPI
  尺寸打开、按钮被裁切；现在随显示器 DPI 正确缩放（100% 缩放下渲染不变）。

### 明细

- 客户端：.NET 8 → **.NET 10 LTS**（`net10.0-windows`，SDK 固定 10.0.402，运行时不低于 10.0.13），
  由 `global.json` 锁定并在构建时校验。
- 新增 UI 回归测试覆盖设置入口：按钮触发共享回调、无局域网地址时入口仍可用、主窗口不显示掩码
  Token 文本、对话框默认掩码 Token 且绝不改写配置、最小窗口尺寸下布局不越界（96–192 DPI）。
- 中继：**无功能变化** —— Python relay 保持 1.0.0；Shortcuts API（`/api/v1/clips`、
  `/api/v1/clips/shortcut`、`/api/v1/clips/latest`）、Bearer Token 认证与默认端口 8787 均未改动，
  既有 iPhone 快捷指令无需任何修改。

### 升级说明（自 v1.0.0）

- 用新目录替换旧目录（或并存后切换）。`config.json`、设备 Token、剪贴板历史与主题设置全部保留；
  打开连接窗口不会重新生成任何值。
- `verify-daily` / `verify-portability` 校验工具、`--doctor` 诊断与托盘工作流行为不变。

---

## Security / 安全

No changes to the security model: LAN-only relay, bearer-token auth, token displayed only on demand
in the read-only connection dialog. / 安全模型无变化：仅局域网中继、Bearer Token 认证、Token 仅在
只读连接窗口按需显示。
